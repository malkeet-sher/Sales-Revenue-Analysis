# Sales & Revenue Analysis

## Project Overview

This project analyzes sales data to understand revenue performance, product performance, category performance, and monthly sales trends.

The project uses Python, SQL, and Tableau Public to perform data analysis and create business insights.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- SQL
- SQLite
- Tableau Public

## Dataset

The dataset contains sales transaction records with the following columns:

- Date
- Product
- Category
- Quantity
- Price
- Revenue

## Analysis Performed

### Python Analysis

- Data loading and inspection
- Data cleaning
- Missing value checking
- Duplicate checking
- Date conversion
- Total revenue calculation
- Product-wise revenue analysis
- Category-wise revenue analysis
- Monthly revenue analysis
- Quantity analysis
- Data visualization

### SQL Analysis

- Total revenue
- Product-wise revenue
- Category-wise revenue
- Month-wise revenue
- Filtering using WHERE
- Filtering grouped data using HAVING
- CASE WHEN conditions
- Common Table Expressions (CTEs)
- Aggregate functions
- JOIN operations
- Window functions
- Product ranking
- Top 3 products by revenue

## Key Insights

- Total revenue generated was ₹5,11,000.
- Laptop generated the highest revenue at ₹3,30,000.
- Monitor generated ₹1,08,000 in revenue.
- Headphones ranked third with ₹35,000 revenue.
- Mouse had the highest quantity sold with 25 units.
- Electronics generated significantly more revenue than Accessories.
- The analysis shows that higher sales volume does not always mean higher revenue because product prices differ.
